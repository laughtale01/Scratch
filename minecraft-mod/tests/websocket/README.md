# WebSocket の受け口の試験

`src/main/java/com/github/minecraftedu/network/SimpleWebSocketServer.java` を、Minecraft を起動せずに確かめる試験です。
Minecraft の部品（`MinecraftServer`・`CommandExecutor`・`MinecraftWebSocketHandler`・ロガー）は `stubs/` の偽物に差し替え、
本物の `SimpleWebSocketServer.java` をそのままコンパイルして動かし、Python から接続を送ります。

## 流し方

```bash
cd minecraft-mod
mise exec -- bash tests/websocket/run.sh
```

- Java 17（`mise.toml` の temurin-17）と python3 が要ります。
- 試験用のポートは 24711 です（本物の MOD の 14711 とぶつからないように）。変えるときは `WS_TEST_PORT=24800` を付けます。
- 2 分ほどかかります（時間切れの確かめで数秒ずつ待つのと、ログの間引きの確かめで 60 秒待つため）。
- MOD のビルド（`./gradlew build`）には含まれません。

## 確かめていること

- つないでよいサイト（Origin）: `https://laughtale01.github.io` と `http://localhost:8000`・`http://127.0.0.1:8000` だけ。無い・ほかのサイトは 403
- 自分の PC 以外（LAN のアドレス）からの接続はすぐ切る（Mac のときだけ確かめる）。IPv6 の `::1` からはつながる
- ヘッダーの上限（1 行 8KB・100 行）ですぐ切る。ハンドシェイクの締め切り（受け付けてから 5 秒。少しずつ送っても延びない）
- ハンドシェイクと最初のフレームが 1 回で届いても、フレームを取りこぼさない
- マスクの無いフレーム、1MB を超えるフレーム、125 バイトを超える制御フレームは切る。Ping には正しい長さの Pong を返す
- 同時接続は 8 本まで。断った接続・切れた接続のあとも枠が戻り、余計にも増えない
- ログ: 受け取った全文を出さない、断った Origin は見える ASCII 以外を `?` にして 100 文字ほどに切る、断った接続のログは理由の種類ごとに 60 秒に 1 行まで（鍵のないリクエスト・長い URL・ハンドシェイクの途中で切られた接続・時間切れも。くり返してもログ全体が DEBUG も含めて増えないことを数える。60 秒たつと間に断った数を書いて 1 行出る）、つながった接続が切れたら info で出す

## 確かめていないこと（試験の外）

- `MinecraftWebSocketHandler` は偽物なので、本物の受信ログ（大きさだけを debug に出す）はこの試験では確かめていない
- 受付のループで Error が起きたときの片付け（枠を返して閉じる）と、失敗が続いたときの 100ms の待ち
- 停止（stop）の途中に来た接続の片付け
- Windows での動き（この試験は Mac で作った）
- `CommandExecutor` の座標と範囲の上限（「ブロックで埋める」「周りをきれいにする」「生き物を全部消す」「ブロックを置く」「テレポート」「生き物を出す」「入れ物にアイテムを入れる」）。下の手順で、本物の MOD で確かめる

## 本物の MOD で上限を確かめる手順

**必ず新しく作った試し用のワールドで行ってください。授業で使うワールド（生徒の作品があるワールド）では行わないでください。**
「周りをきれいにする」などを間違えて動かすと、作品が消えて元に戻せません。

Scratch（gui.js）は体積を先に確かめて断るので、Scratch のブロックからでは MOD 側の確かめまで届かない場合があります。
そのため、命令を MOD へ直接送るスクリプト `probe_fill.py` で確かめます。

1. MOD を新しくビルドして入れ直す（古い MOD のままだと、古い MOD を確かめてしまう）
   - mods フォルダに前の jar（前の名前の `minecraftedu-mod-0.1.0.jar` など）があれば、先に外す（同じ MOD が 2 つあると、どちらが読まれるか分からない）

   ```bash
   cd minecraft-mod
   ./gradlew build
   # build/libs/ にできた jar（minecraftedu-mod-0.1.0-1.20.1.jar）を Minecraft の mods フォルダにコピーし、Minecraft を起動し直す
   ```

2. Minecraft で、新しく作った試し用の**スーパーフラット**のワールドを開く（ふつうのワールドでは流さない。山の頂上などがあると、空気で削れる）
   - **オーバーワールド**（ネザーやエンドではない）にいて、**クリエイティブ**にしておく（y=-60 へテレポートするので、ネザーでは奈落に落ちる。また古い MOD に流すと、ワールドの外へテレポートしてしまうことがあるため）
3. Minecraft と同じ PC の別の端末で、次を実行する（試し用のワールドか聞かれるので、`yes` と入力する。Windows では `python3` の代わりに `py` を使う）

   ```bash
   cd minecraft-mod
   python3 -I tests/websocket/probe_fill.py
   ```

4. 画面に、それぞれの命令の結果（ok / NG）が出る。「断られる」はずの命令のたびにスクリプトが止まるので、ゲームのチャットで「[probe] N 件目」の行のすぐ下に下の表の文が出たかを見て、出たら `y` と入力する（同じ文が続くので、番号の行で前の命令の文と見分ける）
   - 大きな「ブロックで埋める」のあとは、Minecraft が置き終わるまでチャットに出ないことがある。出るまで待ってから答える
   - 途中でプレイヤーを x=1000, y=-60, z=0 へテレポートする（相対座標の確かめのため）。終わったら（NG で止まったときも）元の場所へ戻す
   - はじめに元の場所の座標を表示する。ゲームが落ちたなどで戻せなかったときは「/tp @s x y z で戻ってください」と表示するので、そのとおりに打って戻る
   - 返事だけでは断った理由が分からない（ほかの理由で断られても同じ返事になる）ので、チャットの文で確かめる
   - 期待と違う結果が 1 件でも出たら、そこで止まる。NG のときは、まず mods フォルダの jar が新しくビルドしたもの 1 つだけかを確かめる

座標は Minecraft の座標（F3 で出るもの）です。Scratch のブロックの Y は、これより 60 大きくなります（Minecraft の y=300 は Scratch の y=360）。

「回り込む数」は 4,304,967,296 です。int にすると上の桁が落ちて 10,000,000 になるので、確かめが抜けていると、ワールドの中の遠くの場所として通ってしまいます。

| 送る命令 | 期待する返事 | ゲームのチャット |
|---|---|---|
| 256×1×256（横の上限ちょうど） | 成功（65,536 ブロック） | なし |
| 257×1×256（よこ x の上限を 1 マス超える） | 断られる | 「はんいが広すぎます（よこも おくゆきも 256 マスまで、ぜんぶで 200まん ブロックまで）」 |
| 256×1×257（おくゆき z の上限を 1 マス超える） | 断られる | 「はんいが広すぎます」 |
| 200×100×100 = 2,000,000（体積の上限ちょうど） | 成功（数秒止まることがある） | なし |
| 200×101×100 = 2,020,000（体積の上限を超える） | 断られる | 「はんいが広すぎます」 |
| 高さ 1000〜1010（上の外） | 断られる | 「その高さには ブロックを おけません」 |
| 高さ -1000〜-65（下の外） | 断られる | 「その高さには ブロックを おけません」 |
| 高さ 300〜1000（上だけ外） | 成功（319 まで、720 ブロック） | なし |
| 高さ -1000〜-64（下だけ外。-64 の岩盤に岩盤を置く） | 成功（-64 の 1 ブロック） | なし |
| x = 40,000,000（ワールドの外） | 断られる | 「はんいがワールドの外です」 |
| x = 29,999,999、高さ 1000（ワールドの端の中。高さの理由で断られる） | 断られる | 「その高さには ブロックを おけません」 |
| x = 30,000,000、高さ 1000（ワールドの端ちょうど。置けるのは 29,999,999 まで） | 断られる | 「はんいがワールドの外です」 |
| x = -30,000,000、高さ 1000（ワールドの端の中。高さの理由で断られる） | 断られる | 「その高さには ブロックを おけません」 |
| x = -30,000,001、高さ 1000（ワールドの端の外） | 断られる | 「はんいがワールドの外です」 |
| はじめの x が回り込む数 | 断られる | 「はんいがワールドの外です」 |
| おわりの z だけが回り込む数 | 断られる | 「はんいがワールドの外です」 |
| 周りをきれいにする、中心 x = 40,000,000 | 断られる | 「ばしょがワールドの外です」 |
| 周りをきれいにする、中心 z だけが回り込む数 | 断られる | 「ばしょがワールドの外です」 |
| 生き物を全部消す、中心 x = 40,000,000 | 断られる | 「ばしょがワールドの外です」 |
| 生き物を全部消す、中心 z だけが回り込む数 | 断られる | 「ばしょがワールドの外です」 |
| ブロックを置く、x が回り込む数 | 断られる | 「ばしょがワールドの外です」 |
| ブロックを置く（相対）、ずらす x が回り込む数 | 断られる | 「ばしょがワールドの外です」 |
| テレポート、x = 40,000,000 | 断られる | 「ばしょがワールドの外です」 |
| テレポート、x = 1000, y = -60, z = 0 へ | 成功 | なし |
| ブロックを置く（相対）、x=1000 から 29,999,500 ずらす（足すと外） | 断られる | 「ばしょがワールドの外です」 |
| 生き物を出す、x = 40,000,000 | 断られる | 「ばしょがワールドの外です」 |
| 生き物を出す、z = 40,000,000 | 断られる | 「ばしょがワールドの外です」 |
| 生き物を出す、y = 25,000,000（高さは Minecraft の /summon と同じく -20,000,000 以上 20,000,000 未満） | 断られる | 「ばしょがワールドの外です」 |
| 生き物を出す、y = 20,000,000（高さの上の端ちょうど） | 断られる | 「ばしょがワールドの外です」 |
| 生き物を出す、y = -20,000,001（高さの下の端の外） | 断られる | 「ばしょがワールドの外です」 |
| 入れ物にアイテムを入れる、z が回り込む数 | 断られる | 「ばしょがワールドの外です」 |
| 入れ物にアイテムを入れる、スロット 0（ふつうの番号。y=300 に入れ物は無いので何も変わらない） | 成功 | なし |
| 入れ物にアイテムを入れる、スロット -1 | 断られる | 「その スロットの ばんごうは つかえません」 |
| 入れ物にアイテムを入れる、スロットの番号が回り込む数 | 断られる | 「その スロットの ばんごうは つかえません」 |

- 「成功」の命令は、空の上（y=200 以上）に空気を置く、一番下の岩盤に岩盤を置く、何も無い所の入れ物にアイテムを入れる、プレイヤーをテレポートする、だけです。スーパーフラットのワールドなら見た目は変わらず、プレイヤーも最後に元の場所へ戻ります。
- 「周りをきれいにする」「生き物を全部消す」のふつうの動き（中心から 200 マスを平らにする・生き物を消す）は、このスクリプトでは試しません。試すときも試し用のワールドで行ってください。
