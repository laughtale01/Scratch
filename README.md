# Scratch 3.0 + Minecraft 拡張機能

Scratch 3.0 をベースにした、Minecraft Java Edition と連携できるビジュアルプログラミング環境です。

## デモ

**https://laughtale01.github.io/Scratch**

## 特徴

- **Scratch 3.0 GUI** - 公式 Scratch 3.0 と同等の機能
- **Minecraft 拡張機能** - Minecraft Java Edition をプログラムで制御
- **日本語対応** - 日本語インターフェース
- **ブラウザで動作** - インストール不要、すぐに使える

## Minecraft 拡張機能について

Scratch のブロックを使って、Minecraft の世界を操作できます。

### 主な機能

- ブロックの配置・破壊
- プレイヤーの移動
- 各種ブロックの選択（建築ブロック、装飾ブロック、自然ブロック等）
- WebSocket による Minecraft MOD との通信

### 対応ブロック

700種類以上の Minecraft ブロックに対応しています：

- 建築ブロック（石、レンガ、木材など）
- 照明ブロック（松明、ランタンなど）
- 装飾ブロック（カーペット、旗など）
- 自然ブロック（草、花、葉など）
- 機能ブロック（チェスト、作業台など）
- 鉱石ブロック（ダイヤモンド、金など）
- 特殊ブロック

## 使い方

1. https://laughtale01.github.io/Scratch にアクセス
2. 左下の「拡張機能を追加」ボタンをクリック
3. 「Minecraft」を選択
4. Minecraft ブロックを使ってプログラミング

## 必要環境

- **Chromium系ブラウザ**（Chrome, Edge, Brave, Opera など）
- Minecraft Java Edition（MOD連携時）

> **注意**: Safari では正常に動作しません。Chrome または Edge の使用を推奨します。
