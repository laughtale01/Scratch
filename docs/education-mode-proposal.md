# Minecraft Education Mode - 段階的建築学習システム

## 概要

Scratch + Minecraft拡張機能を活用した教育向け機能の提案書です。
生徒がプログラミングを通じて建築を学ぶための「段階的手本表示システム」を提案します。

---

## 1. コンセプト

### 1.1 教育目標

- プログラミングの基礎概念（ループ、座標、変数）を建築を通じて学ぶ
- 段階的な課題で達成感を得ながら学習を進める
- 手本を見ながら自己ペースで学習できる環境を提供

### 1.2 基本アイデア

建築物を10の層（段階）に分け、各段階の累積状態を手本として配置。
生徒はセーブデータをロードし、手本を参考にしながらScratchでプログラミングを行う。

```
┌─────────────────────────────────────────────────────────────┐
│                    Minecraftワールド                         │
│                                                             │
│  【生徒作業エリア】          【手本エリア X:300〜】           │
│                                                             │
│   X:0, Z:0                  段階1  段階2  段階3 ... 段階10   │
│   ┌─────┐                   ┌─┐   ┌─┐   ┌─┐       ┌─┐      │
│   │     │                   │1│   │2│   │3│       │完│      │
│   │ 生徒│                   │層│   │層│   │層│  ...  │成│      │
│   │ 建築│                   │ │   │+│   │+│       │形│      │
│   │     │                   │ │   │1│   │2│       │ │      │
│   └─────┘                   └─┘   └─┘   └─┘       └─┘      │
│                             X:300 X:330 X:360     X:570    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 詳細設計

### 2.1 ワールド配置

| エリア | 座標 | 用途 |
|--------|------|------|
| 生徒作業エリア | X:0, Y:0, Z:0 | Scratchから建築を行う場所 |
| 手本エリア | X:300〜, Z:300 | 段階別の手本建築物を配置 |

### 2.2 手本配置の詳細

```
段階1:   X:300,  Z:300  → 1層のみ
段階2:   X:330,  Z:300  → 1層 + 2層
段階3:   X:360,  Z:300  → 1層 + 2層 + 3層
段階4:   X:390,  Z:300  → 1層 + 2層 + 3層 + 4層
段階5:   X:420,  Z:300  → 1層 + 2層 + 3層 + 4層 + 5層
段階6:   X:450,  Z:300  → 1層 + 2層 + 3層 + 4層 + 5層 + 6層
段階7:   X:480,  Z:300  → 1層 + 2層 + 3層 + 4層 + 5層 + 6層 + 7層
段階8:   X:510,  Z:300  → 1層 + 2層 + 3層 + 4層 + 5層 + 6層 + 7層 + 8層
段階9:   X:540,  Z:300  → 1層 + 2層 + 3層 + 4層 + 5層 + 6層 + 7層 + 8層 + 9層
段階10:  X:570,  Z:300  → 完成形（全10層）
```

- **間隔**: 30ブロック（建築物サイズ + 余白）
- **Y座標**: 地面レベル（通常Y:64〜65）

### 2.3 学習フロー

```
┌─────────────────────────────────────┐
│ 1. セーブデータをロード              │
│    (手本建築済みワールド)            │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│ 2. 段階Nの手本を確認                 │
│    /tp @p [X座標] 65 300            │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│ 3. 作業エリアに戻る                  │
│    /tp @p 0 65 0                    │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│ 4. Scratchでプログラミング           │
│    - ブロック配置のコードを作成       │
│    - 実行して確認                    │
└─────────────────┬───────────────────┘
                  ↓
┌─────────────────────────────────────┐
│ 5. 手本と比較                        │
│    - 正しければ次の段階へ            │
│    - 間違いがあれば修正              │
└─────────────────┬───────────────────┘
                  ↓
         (段階2〜10を繰り返し)
```

### 4.2 実装詳細

#### 4.2.1 手本を見るブロック

```javascript
// gui.js への追加案
{
  opcode: 'viewExample',
  blockType: 'command',
  text: formatMessage({
    id: 'minecraft.viewExample',
    default: 'view example stage [STAGE]',
    description: 'teleport to example building'
  }),
  arguments: {
    STAGE: {
      type: 'number',
      menu: 'stageMenu',
      defaultValue: 1
    }
  }
}

// 実装
viewExample(args) {
  const stage = Number(args.STAGE);
  const x = 300 + (stage - 1) * 30;
  const y = 65;
  const z = 300;
  return this.sendCommand('teleport', { x, y, z });
}
```

## 6. 運用ガイド

### 6.1 事前準備（先生向け）

1. **ワールド作成**
   - 新規ワールドを作成（クリエイティブモード推奨）
   - ゲームルール設定:
     ```
     /gamerule doDaylightCycle false
     /gamerule doWeatherCycle false
     /gamerule doMobSpawning false
     ```

2. **手本建築**
   - X:300, Z:300 を起点に段階1〜10の手本を配置
   - 各手本の間隔は30ブロック

3. **案内看板設置**（任意）
   ```
   各手本の前に看板を設置:
   ┌──────────────┐
   │ 段階 N       │
   │ 1〜N層       │
   │ 次→ X:XXX   │
   └──────────────┘
   ```

4. **セーブデータ配布**
   - ワールドフォルダを圧縮
   - 生徒に配布（USBメモリ、クラウドストレージ等）

### 6.2 授業の流れ

| 時間 | 内容 |
|------|------|
| 0:00 | セーブデータの展開、Minecraft起動 |
| 0:05 | MOD接続確認、Scratch起動 |
| 0:10 | 段階1の手本確認 |
| 0:15 | 段階1のプログラミング開始 |
| 0:30 | 段階1の確認、段階2へ |
| ... | 繰り返し |

### 6.3 トラブルシューティング

| 問題 | 対処法 |
|------|--------|
| 接続できない | MODが正しくインストールされているか確認 |
| ブロックが置けない | 作業エリアの座標を確認 |
| 手本が見つからない | /tp コマンドの座標を確認 |
| やり直したい | /fill コマンドで作業エリアをクリア |

### 8.2 座標系

```
Scratch座標 → Minecraft座標
Y座標は -60 オフセット
例: Scratch Y:0 = Minecraft Y:-60
    Scratch Y:60 = Minecraft Y:0
    Scratch Y:125 = Minecraft Y:65 (地表)
```

### 8.3 現行の主要ブロック

```
接続系:
- Minecraftに接続 ホスト [HOST] ポート [PORT]
- 切断
- 接続中?

ブロック配置:
- ブロックを置く X:[X] Y:[Y] Z:[Z] ブロック:[BLOCK]
- 範囲を埋める [X1][Y1][Z1] から [X2][Y2][Z2] を [BLOCK] で

移動:
- テレポート [X] [Y] [Z]
- プレイヤーの位置 [X/Y/Z]

ワールド:
- 天気を [WEATHER] にする
- 時刻を [TIME] にする
- エリアをクリア
```
